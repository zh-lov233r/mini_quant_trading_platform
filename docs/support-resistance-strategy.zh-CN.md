# 支撑压力策略

[English](support-resistance-strategy.md) | [文档索引](README.zh-CN.md)

`support_resistance` 是仅做多日线策略，唯一执行实现为共享 C++ 内核。回测与 Paper 采用同一检测器、信号及风险规则。创建策略不会启用调度或授权券商操作。

## 冻结区域与阶段

- Pivot 默认左右各 3 根 K 线，右侧完成才确认。极值在候选 ATR 的 0.05 内视为并列，取最早日期。
- 使用加权 Theil–Sen，至少 2 个已确认 Pivot、跨度至少 10 个交易日。候选依据同时受 120 日检测窗口及当前阶段极值日期限制；ATR 和 OHLC 历史不重置。
- 按成员数、时间权重、残差、价格距离和 Pivot key 确定性排序。每种来源最多 3 区（可配 1–5）；已有区域占用名额，不允许替换。
- 半宽取 0.5 当前 ATR 与成员最大残差的较大者。确认后成员、锚点、斜率、宽度、角色永久冻结，只沿原斜率延伸。价格上涨不会把压力转换为支撑。
- 全部区域（含不同角色）互不重叠。候选在共同拟合/有效历史范围内接触或穿越已有区域就拒绝，不移动或缩窄旧区。
- 每日信号判断前检查：非法几何、投影接触/相交、收盘严格低于支撑下沿或高于压力上沿，均结束整个阶段。原因分别为 `invalid_geometry`、`zone_conflict`、`close_break`。
- 收盘等于边界不破坏。影线越界后收回只算触碰；连续停留区域内只算一次触碰过程。
- 破坏日 T 是新阶段起点，全部旧区截止上一实际交易日。T 不允许基于旧区买入。新拟合只能使用极值日期在 T 及之后且已确认的 Pivot；不足时等待，不借用旧成员。

阶段身份与上行/下行/震荡/过渡分类独立。结构不足归入过渡。分类证据仅使用当前阶段已确认 Pivot；固定成员退出候选回看窗口后仍保留审计依据。

## 信号、重复交易与执行

T 收盘确认的区域最早在 T+1 判断信号。行情优先前复权 OHLC，否则使用未复权数据。信号仍在下一有效交易日开盘成交；卖出优先、共享现金、费用、公司行动和确定性排序不变。

仅保留 `support_bounce` 入场：前收盘在冻结支撑上沿上方，当前最低价触碰，收盘恢复到上沿加至少 0.25 ATR。上行/震荡允许，下行/过渡禁止。移除直接突破与突破回踩开关、触发参数及消费者；其他策略回踩规则不变。

同一个股可以在未改变的区域内反复交易。上一持仓平仓后，再次满足反弹条件可重新入场，不设置“每区一次”标志。现有持仓、强度、风险、大盘过滤及区域止损冷却仍生效。

强度权重保持盈亏比 25%、成员数 15%、真实触碰 10%、拟合质量 15%、距支撑近度 20%、成交量 15%；默认最低 50。这些只是工程默认值，不是盈利证据。

选收盘下方最近冻结支撑上沿及上方最近压力下沿组成严格有序通道。下一有效开盘投影冻结通道，复核含滑点价格、费用、盈亏比、风险预算、现金和持仓限制。不放宽通道，拒单不改变现金或持仓。

初始止损取冻结支撑下沿、1.5 ATR、8% 收盘止损参考线中最严格者；目标取最近上方压力，没有则用 3 ATR。毛盈亏比默认至少 1.5，执行时扣费复核。计划风险默认权益 0.5%，名义仓位上限默认 15%。

阶段结束不强制清仓。已有持仓保留入场冻结止损/目标，继续收盘止损、目标、下行、最长持有退出。止损不放松；此前收盘达到 1R 后提高到成本。止损信号默认冷却同一区域随后 5 个交易日。跳空损失可超过模型风险。

后验结局只是描述统计，不参与买入排序，也不是校准置信度。每个标的/模式一个待结算假设结局，不限制真实重复交易。

## 生命周期图

SR 常态仅展示 K 线、成交量、支撑/压力区、买卖信号和成交。无常驻 Pivot、触碰或审计点，无青色通道、阶段背景及对应图例。

最早拟合 Pivot 至确认日为浅色虚线事后拟合段，当时不可交易。实线有效段保留冻结几何，在阶段结束时停止。两段均裁剪到当前窗口，不改变缩放、不跨阶段拼接。非法历史投影标记不可用，不伪造。

默认依据持久化入场/退出证据筛选交易关联区，“显示全部区域”恢复窗口内其他区域。悬停命中真实倾斜带后突出一个区域及其固定成员/真实触碰；窗口外 Pivot 仅列日期，不伪造位置。上下标注带与引导线避让 K 线和成交量。点击固定，空白点击或 Escape 清除；共享工作区选择框支持键盘和触屏。边缘多命中默认最近中线，可用选择框切换。悬停不请求数据、不重建图表。

## 持久化与缓存

检测器 revision **13**、状态 revision **4**，算法族 `pivot-slope-regime-v3`。旧 revision 不可用于新计算。

现有区域、状态和事件表保存阶段身份、确认日期、结束原因和破坏日证据。区域 key 包含阶段；只保存一次活动几何及终态，不改拟合依据。即便相邻阶段都是等待/过渡，状态证据也记录新起点。缓存回放恢复这些空阶段，并要求与冷计算决策/事件一致。

`GET /api/backtests/{run_id}/support-resistance` 返回裁剪后的 `geometry`、可空 `formation_geometry`、固定成员/阶段元数据及真实事件，使用该 instrument 实际交易日查询行情。

阶段 JSON 元数据不需要新增 schema 或 Alembic 迁移。空闲后端/worker 重启前重建原生扩展：

```bash
.venv/bin/pip install --no-build-isolation --no-deps -e backend/native
```

本地回测验证期间设置 `PAPER_TRADING_SCHEDULER_ENABLED=false`、`PAPER_TRADING_SCHEDULER_SUBMIT_ORDERS=false`。已有券商订单与持仓不在本流程范围内。

## 已授权旧结果清理与恢复

限定目标为本机 PostgreSQL `localhost:5432/hzy`、schema `public`。执行前冻结旧运行/物化精确 ID，复核状态、引用、行数。遇活动任务或意外引用立即停止，不自动取消或扩大范围。

在仓库外备份目标行、表结构、依赖顺序、行数和校验信息，确认可读后才删除。在一个受控事务中复用终态回测删除（包括显式删除成交），再删除已无引用的冻结旧物化 ID 及区域/状态行。禁止 truncate 或整库重置。

保留策略、股票组合、原始数据、日频特征、其他策略结果、Paper/live、下载报告和券商状态。新规则验证结果不得进入旧目标清单。删除后验证旧 ID 不存在/404，保留对象未变。

按依赖顺序从保留备份恢复原 ID。任何 ID/引用冲突都停止并回滚，不覆盖新数据。表结构仅供恢复参考，不授权重建或删除现有表。
